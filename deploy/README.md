## Диски

Используются существующие Docker volumes OMV, без прямого доступа к блоковым устройствам:

| Диск | Docker volume | Путь менеджера | Путь qBittorrent |
| --- | --- | --- | --- |
| Медиатека · 10 ТБ | `omv_media1` | `/storage/hdd1` | `/data/media1` |
| Медиатека · 18 ТБ | `omv_media2` | `/storage/hdd2` | `/data/media2` |

Volumes подключены к менеджеру только для чтения. Контейнер работает от UID/GID 1000,
с лимитом памяти 512 МиБ и heap 256 МиБ. Корневая файловая система контейнера доступна
только для чтения; `config`, `data`, `logs` и временный каталог смонтированы отдельно.

## Обновление

1. Соберите и проверьте новую версию: `gradlew.bat test bootJar`.
2. Перед заменой JAR сохраните предыдущую сборку и конфигурацию, а также резервную копию `config` и `data`.
3. Разместите новую сборку по указанному абсолютному пути JAR.
4. Пересоздайте контейнер через Portainer → Stacks → torrent-manager → Editor → Update the stack.
5. Проверьте статус `healthy`, `/actuator/health` и соединение с qBittorrent.

Проверка здоровья обращается к `/actuator/health`. Ещё не настроенный или выключенный
SMTP не делает приложение нездоровым; SMTP проверяется отдельной кнопкой панели.

Исходная установка через SSH Compose была заменена Stack Portainer. Состояние сохранено,
резервная копия до переноса находится в `/opt/stacks/torrent-manager/before-portainer-20261110-201241`.
