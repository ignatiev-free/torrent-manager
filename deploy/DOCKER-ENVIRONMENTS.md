# Стандарт Docker-окружений

| Проект | Постоянный Stack | Постоянные контейнеры |
| --- | --- | --- |
| Homelab AI Assistant | `homelab-ai-assistant` | `homelab-ai-assistant`, `homelab-ai-assistant-postgres` |
| Torrent Manager | `torrent-manager` | `torrent-manager` |

Версию приложения указывайте в теге образа, метаданных сборки и сведениях о запущенном приложении. Для нескольких сборок используйте тег `<version>-<short-sha>` в рамках одного Stack. Для Torrent Manager с внешним JAR фиксируйте также версию приложения, SHA коммита и SHA-256 JAR, поскольку тег базового JRE относится к среде выполнения.

Для временного окружения на Docker VM используйте `<project>-<version>-test`, например `homelab-ai-assistant-0.5.0-test`, `homelab-ai-assistant-0.5.1-test` или `torrent-manager-0.10.0-test`. Имена вспомогательных контейнеров, сетей и временных томов должны начинаться с имени соответствующего тестового Stack. По умолчанию на проект приходится не более одного активного тестового окружения. Для разработки и интеграционных проверок отдавайте предпочтение локальным тестам и Testcontainers.

Каждому тестовому окружению выделяйте отдельную PostgreSQL или изолированную тестовую базу, собственные временные тома, очереди уведомлений и receipts. Проверяйте конфликты портов. Для каждого Telegram-токена допускается один активный poller. Отправка реальных уведомлений по умолчанию выключена. Для qBittorrent используйте имитатор, отдельный экземпляр или доступ, исключающий неконтролируемые изменения состояния. NAS подключайте только в режиме read-only.

После приёмки обновите постоянный Stack согласованной сборкой, проверьте сервис и сохраните предыдущую проверенную сборку для отката. Затем проверьте временное окружение на уникальные данные, сохраните нужное и удалите завершённый Stack вместе с его временными ресурсами и ненужными промежуточными образами. Проверяйте принадлежность ресурсов проекту и ссылки на них. Удаление томов и каталогов с постоянными данными требует отдельного согласования.

Новый стандарт применяется при развёртывании. Для существующего Stack, которому нужна миграция имён, заранее согласуйте окно переключения и явно закрепите используемые тома, сети и DNS-алиасы в Compose.
